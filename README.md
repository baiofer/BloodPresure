# Monitor de Tensión Arterial 🩺

Aplicación web desarrollada en React para registrar y monitorear la presión arterial.

## Características

- ✅ Interfaz responsive (móvil a escritorio)
- 📊 Registro de presión arterial (sistólica/diastólica)
- ❤️ Registro opcional de pulso
- 🎯 Clasificación automática según estándares médicos
- 📝 Historial de lecturas (últimas 10)
- 💾 Almacenamiento local persistente
- 🎨 Diseño moderno y atractivo

## Clasificación de la Presión Arterial

- **Normal**: <120 / <80 mmHg
- **Elevada**: 120-129 / <80 mmHg
- **Hipertensión Etapa 1**: 130-139 / 80-89 mmHg
- **Hipertensión Etapa 2**: ≥140 / ≥90 mmHg

## Instalación y Uso

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Vista previa de la compilación
npm run preview
```
